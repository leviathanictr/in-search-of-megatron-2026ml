# In Search of Megatron — модель v12

Решение команды **In Search of Megatron** на соревнование
[Kaggle: 2026 Поиск нейтронов с помощью методов ML](https://www.kaggle.com/competitions/2026-ml).

Метод: расширенная PSD-разметка + двухраундовый ансамбль
**Random Forest + Gradient Boosting + CatBoost + SVM** с полу-обучением
(self-training) во втором раунде. Public LB — **0.89820**.

> Преемственность с подходом А. В. Николаева и др. («Применение
> Градиентного Бустинга с Первоначальной Разметкой PSD», 2025): сохранена
> идея PSD-разметки и градиентного бустинга, но добавлены физическая
> параметризация формы сигнала, PCA по выровненным импульсам, оконные
> интегралы хвоста, многоуровневая фильтрация аномалий и итеративное
> самообучение.

## Быстрый старт

```bash
# 1. Клонировать
git clone https://github.com/leviathanictr/in-search-of-megatron-2026ml.git
cd in-search-of-megatron-2026ml

# 2. Поставить зависимости (Python 3.11+)
python -m venv .venv && . .venv/Scripts/activate    # Windows
pip install -r requirements.txt

# 3. Скачать data_set_1.csv с Kaggle и положить в data/
#    (см. data/README.md)

# 4. Полный пайплайн (≈30–60 минут на CPU)
python src/run.py
```

После выполнения в `artifacts/verdict_v12_cat3_svm3.csv` появится готовый
submission в формате `Id, Predicted`.

## Описание метода (коротко)

### 1. Параметризация сигнала

Из каждого сигнала длиной 496 АЦП-отсчётов извлекаются:

- **Базовая линия** — медиана первых 80 отсчётов.
- **Амплитуда** = базовая − минимум; **площадь** = сумма положительной части.
- **PSD CAEN** = (Q_long − Q_short) / Q_long, где Q-значения уже посчитаны платой.
- **PSD local** — то же, посчитанное по форме сигнала вручную.
- **Сегментные интегралы** (short / mid / tail / tail_far) и их доли.
- **Времена нарастания и спада** на уровнях 10 % и 90 %.
- **Ширина на полувысоте** и на 20 % амплитуды.
- **Асимметрия** (отношение пост- и пред-пика).
- **Шум базовой линии и хвоста**, **число пиков**, **скос/эксцесс**
  энергетического распределения.

### 2. Дополнительные признаки

- **PCA-проекция** выровненных по пику сигналов (10 компонент).
- **8 окон-интегралов** после пика разной длины (для разрешения скорости
  затухания на разных временных масштабах).
- **Доля энергии в позднем хвосте** (>80 и >200 отсчётов после пика).
- **Центроид** распределения энергии.

### 3. Псевдо-разметка по PSD

```python
gam = (psd < 0.13) & (amp > 400) & (95 <= peak_pos <= 115)
neu = (psd >= 0.24) & (psd <= 0.32) & (amp > 400) & (95 <= peak_pos <= 115)
noise = (FLAGS != "0x4000") | sat | (baseline_noise > 80) | extreme_peak | many_peaks | low_amp
```

Промежуточные события (0.13 ≤ PSD < 0.24) при первом раунде из обучения
исключаются.

### 4. Ансамбль и самообучение

| Раунд | Что делается |
|------:|--------------|
| 1 | На rules-метках обучаются **RF**, **GB**, **CatBoost**. Soft-voting. |
| — | События с уверенностью > 0.85 становятся новой обучающей выборкой. |
| 2 | Переобучаются **RF / GB / CatBoost**, добавляется **SVM** (RBF, балансированная подвыборка 7000 на класс). |
| вых.| Голосование `(1·RF + 1·GB + 3·CatBoost + 3·SVM) / 8`. |

## Воспроизводимость

- Все random_state зафиксированы (`0` для round 1, `1` для round 2, `7` для подвыборки SVM).
- Версии библиотек закреплены в `requirements.txt`.
- На том же `data_set_1.csv` запуск `python src/run.py` даёт побайтово
  идентичный submission.

## Что в репозитории НЕТ

- `data_set_1.csv` — не коммитим (правила Kaggle + 100 МБ).
- Pickled-модели — заново обучаются за 30–60 минут, поэтому в репозиторий
  не кладутся.
- `adc_raw.npy` — большой промежуточный артефакт, генерируется при первом
  запуске `load_data.py`.
